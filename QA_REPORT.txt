LIMITACIÓN DEL ENTORNO DE ENTREGA
El registro npm no estuvo accesible desde el entorno de empaquetado, por lo que no se pudo ejecutar `npm install` + `vite build` aquí. Las versiones están fijadas y el código pasó smoke tests del motor y chequeo sintáctico JSX. Ejecutar `npm install && npm run build` en un entorno con acceso a npm es la última comprobación de integración.

RIESGOS DE BALANCE A VALIDAR EN v0.2
- La economía necesita simulaciones de 5-15 temporadas para calibrar escalado.
- Global fans todavía es un modelo simplificado.
- Sponsors y merchandising necesitan elasticidad de precio más profunda.
- El motor deportivo POC es agregado y no incluye lesiones, fatiga ni estadísticas individuales.
